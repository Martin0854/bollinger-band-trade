## ⚠️ 주의사항

### 1. 데이터 가용성
- yfinance는 보통 **2000년 이후** 데이터 제공
- 오래된 데이터일수록 누락 가능성 있음
- 2015년 이후 데이터가 가장 안정적

### 2. 최소 데이터 요구량
- 볼린저 밴드 계산: **최소 20일**
- 스퀴즈 감지: **추가 10일**
- **권장: 최소 50일 이상**

### 3. 백테스트 시간
- 1년 데이터: ~2-3분 (10종목)
- 3년 데이터: ~5-10분 (10종목)
- 데이터가 많을수록 시간 증가

### 4. 시장 환경
- **2020년**: 코로나 폭락 + 회복 (변동성 극대)
- **2021년**: 강한 상승장
- **2022년**: 조정장/하락장
- **2023년**: 회복/횡보
- **2024년**: 횡보/변동성

## 🔧 자동화 스크립트 (여러 기간 테스트)

다양한 기간으로 자동 백테스트:

```python
# test_multiple_periods.py
from run_multi_backtest import run_multi_backtest, load_stock_list

stocks = load_stock_list("kospi_top100.txt")

periods = [
    ("2022-01-01", "2022-12-31"),  # 2022년
    ("2023-01-01", "2023-12-31"),  # 2023년
    ("2024-01-01", "2024-12-31"),  # 2024년
]

for start, end in periods:
    print(f"\n{'='*80}")
    print(f"백테스트 기간: {start} ~ {end}")
    print(f"{'='*80}\n")

    run_multi_backtest(
        stock_codes=stocks,
        start_date=start,
        end_date=end,
        seed_money=10_000_000,
        max_stocks=10,  # 테스트용
        bollinger_period=20,
        squeeze_threshold_percent=30,
        stop_loss_percent=5.0,
        max_position_percent=30.0
    )
```

실행:
```bash
poetry run python test_multiple_periods.py
```
