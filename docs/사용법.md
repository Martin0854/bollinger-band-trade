## 💡 기본 사용법

### 방법 1: Python 스크립트 (추천)

```python
import pandas as pd
from datetime import date
from src.models.config import BacktestConfiguration
from src.backtest.engine import BacktestEngine

# 1. 설정
config = BacktestConfiguration(
    seed_money=10_000_000,      # 1000만원
    stocks=["005930"],          # 삼성전자
    date_range=(date(2024, 1, 1), date(2024, 12, 31)),
    stop_loss_percent=5.0       # 5% 손절
)

# 2. 가격 데이터 준비
dates = pd.date_range('2024-01-01', '2024-12-31', freq='D')
price_data = pd.DataFrame({
    'Open': [...],    # 시가
    'High': [...],    # 고가
    'Low': [...],     # 저가
    'Close': [...],   # 종가
    'Volume': [...]   # 거래량
}, index=dates)

# 3. 백테스트 실행
engine = BacktestEngine(config)
engine.load_mock_data("005930", price_data)
report = engine.run()

# 4. 결과 확인
print(f"수익률: {report.total_return_pct}%")
print(f"승률: {report.win_rate_pct}%")
```

## ⚙️ 설정 파라미터

### 필수 파라미터

| 파라미터 | 설명 | 예시 |
|---------|------|------|
| `seed_money` | 초기 자본 (원) | `10_000_000` |
| `stocks` | 종목 코드 리스트 | `["005930", "035720"]` |
| `date_range` | 백테스트 기간 | `(date(2024,1,1), date(2024,12,31))` |

### 전략 파라미터 (기본값 있음)

| 파라미터 | 설명 | 기본값 | 범위 |
|---------|------|--------|------|
| `bollinger_period` | 이동평균 기간 | 20일 | 5-200 |
| `bollinger_std_dev` | 표준편차 배수 | 2.0 | 0-5 |
| `squeeze_threshold_percent` | 스퀴즈 감지 임계값 | 30% | 5-100 |
| `squeeze_lookback_days` | 비교 기간 | 10일 | 2-30 |

### 리스크 관리 파라미터

| 파라미터 | 설명 | 기본값 | 범위 |
|---------|------|--------|------|
| `stop_loss_percent` | 손절매 비율 | 5% | 0-100 |
| `max_position_percent` | 종목당 최대 비중 | 30% | 0-100 |
| `max_positions` | 최대 동시 보유 종목 | 5개 | - |

## 📊 실전 예제

### 예제 1: 보수적 전략

```python
config = BacktestConfiguration(
    seed_money=10_000_000,
    stocks=["005930"],              # 대형주 1종목
    date_range=(date(2024, 1, 1), date(2024, 6, 30)),
    bollinger_period=30,            # 긴 기간 (덜 민감)
    bollinger_std_dev=2.5,          # 넓은 밴드 (신호 적음)
    squeeze_threshold_percent=40,   # 엄격한 스퀴즈 감지
    stop_loss_percent=3.0,          # 타이트한 손절
    max_position_percent=20.0,      # 작은 포지션
    max_positions=3                 # 적은 동시 포지션
)
```

**특징:**
- ✅ 낮은 리스크
- ✅ 적은 거래 횟수
- ❌ 낮은 수익 기회

## 📈 결과 해석

### 백테스트 결과 보는 법

```python
report = engine.run()

# 수익성 지표
print(f"총 수익률: {report.total_return_pct}%")      # 전체 수익률
print(f"연평균 수익률(CAGR): {report.cagr_pct}%")   # 연환산 수익률

# 승률 지표
print(f"승률: {report.win_rate_pct}%")              # 수익 거래 비율
print(f"평균 수익: ₩{report.avg_win:,}")           # 평균 수익 금액
print(f"평균 손실: ₩{report.avg_loss:,}")          # 평균 손실 금액
print(f"손익비: {report.win_loss_ratio}")          # 평균수익/평균손실

# 리스크 지표
print(f"최대 낙폭(MDD): {report.max_drawdown_pct}%")  # 최대 하락폭
print(f"샤프 비율: {report.sharpe_ratio}")            # 위험조정 수익률
print(f"수익 팩터: {report.profit_factor}")          # 총수익/총손실
```

### 지표 해석 가이드

| 지표 | 좋은 값 | 의미 |
|------|--------|------|
| **총 수익률** | > 10% | 전체 기간 수익 |
| **승률** | > 55% | 수익 거래 비율 |
| **최대 낙폭(MDD)** | < -20% | 최악의 하락폭 |
| **샤프 비율** | > 1.0 | 위험 대비 수익 |
| **손익비** | > 2.0 | 평균수익/평균손실 |
| **수익 팩터** | > 1.5 | 총수익/총손실 |

## ❓ 문제 해결

### 거래가 전혀 실행되지 않음

**증상:** `report.num_trades == 0`

**해결 방법:**
1. **데이터 확인**: 가격 변동성이 충분한가?
2. **스퀴즈 임계값 조정**: `squeeze_threshold_percent`를 20-25%로 낮추기
3. **기간 확인**: 최소 50일 이상의 데이터 필요
4. **데이터 형식 확인**:
   ```python
   # 올바른 형식
   print(price_data.columns)  # ['Open', 'High', 'Low', 'Close', 'Volume']
   print(price_data.index)    # DatetimeIndex
   ```

### ValidationError 발생

```python
from pydantic import ValidationError

try:
    config = BacktestConfiguration(...)
except ValidationError as e:
    print(e.errors())  # 어떤 필드가 잘못되었는지 확인
```

**흔한 오류:**
- ❌ `seed_money`가 음수
- ❌ 종목 코드가 6자리가 아님 (예: "5930" → "005930")
- ❌ 시작일이 종료일보다 늦음
- ❌ `bollinger_period`가 5-200 범위 밖
- ❌ `stop_loss_percent`가 0-100 범위 밖

### 데이터가 부족함

**증상:** 볼린저 밴드가 계산되지 않음

**최소 데이터 요구사항:**
- 볼린저 밴드: `bollinger_period`일 (기본 20일)
- 스퀴즈 감지: 추가 `squeeze_lookback_days`일 (기본 10일)
- **권장**: 최소 50일 이상의 데이터
