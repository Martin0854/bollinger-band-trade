## 📊 핵심 지표 설명

### 1. 볼린저 밴드 (Bollinger Bands)

**구성:**
```
상단 밴드 (Upper Band)  = 중간선 + (표준편차 × 2)
중간선 (Middle Band)    = 20일 이동평균선 (SMA)
하단 밴드 (Lower Band)  = 중간선 - (표준편차 × 2)
```

**의미:**
- **상단 밴드**: 과매수 구간 (가격이 높음)
- **중간선**: 평균 가격 (20일 기준)
- **하단 밴드**: 과매도 구간 (가격이 낮음)

**시각적 표현:**
```
                    ╔════════════╗  ← 상단 밴드 (78,699원)
                    ║            ║
   가격 → ★         ║  변동 구간 ║
                    ║            ║
   ─────────────────●────────────  ← 중간선 (74,774원)
                    ║            ║
                    ║            ║
                    ╚════════════╝  ← 하단 밴드 (70,849원)
```

**예시 (삼성전자 2024-03-20):**
```
상단 밴드:  ₩78,699
중간선:     ₩74,774
하단 밴드:  ₩70,849
현재가:     ₩74,373
```

---

### 2. 대역폭 (Bandwidth)

**계산 공식:**
```
대역폭 = (상단 밴드 - 하단 밴드) / 중간선
```

**의미:**
- **높은 대역폭 (>15%)**: 변동성 높음, 가격 변화 큼
- **보통 대역폭 (10-15%)**: 정상 변동성
- **낮은 대역폭 (5-10%)**: 횡보장, 변동성 낮음
- **매우 낮은 대역폭 (<5%)**: 스퀴즈 상태, 곧 큰 움직임 예상

**예시:**
```
대역폭 5.8%  → 스퀴즈 상태 🔴
대역폭 10.5% → 정상
대역폭 16.5% → 확장 (변동성 증가)
```

**계산 예시 (삼성전자):**
```
상단: 78,699원, 하단: 70,849원, 중간: 74,774원
대역폭 = (78,699 - 70,849) / 74,774 = 7,850 / 74,774 = 0.105 = 10.5%
```

---

### 3. 스퀴즈 (Squeeze)

**정의:**
대역폭이 과거 10일 대비 30% 이상 감소한 상태

**스퀴즈 감지 조건:**
```python
# 오늘 대역폭이 10일 전 대역폭의 70% 이하
현재 대역폭 < 10일 전 대역폭 × (1 - 0.30)
```

**예시:**
```
10일 전 대역폭: 15%
현재 대역폭:    8%
감소율: (15-8)/15 = 46.7% 감소 ✅ 스퀴즈 감지!
```

**스퀴즈가 의미하는 것:**
1. 📉 **변동성 축소**: 가격이 좁은 범위에서 움직임
2. ⏸️ **관망 국면**: 매수/매도 세력이 균형
3. ⚡ **에너지 축적**: 곧 큰 가격 움직임 예상
4. 🎯 **돌파 대기**: 상향 또는 하향 돌파 임박

**시각적 표현:**
```
스퀴즈 전 (대역폭 넓음)          스퀴즈 중 (대역폭 좁음)

    ╔═══════════════╗               ╔═════╗
    ║               ║               ║     ║
    ║   ★  ★   ★   ║      →        ║ ★★★ ║  ← 가격 횡보
    ║               ║               ║     ║
    ╚═══════════════╝               ╚═════╝

     변동성 큼                       변동성 작음
```

## 🔴 매수 타이밍 (진입 신호)

### 조건 1: 스퀴즈 감지

먼저 스퀴즈가 발생해야 합니다.
```
✅ 대역폭이 과거 10일 대비 30% 이상 감소
✅ 스퀴즈 상태로 진입
```

### 조건 2: 상단 밴드 돌파

스퀴즈 감지 **이후**, 가격이 상단 밴드를 돌파해야 합니다.
```
✅ 현재가 > 상단 밴드
✅ 상승 돌파 확인
```

### 조건 3: 대역폭 확장

돌파와 동시에 대역폭이 확장되어야 합니다.
```
✅ 현재 대역폭 >= 최소 대역폭 × 1.1
✅ 변동성 증가 확인
```

### 매수 실행 조건 정리

```python
if (스퀴즈 감지됨 AND
    현재가 > 상단_밴드 AND
    대역폭이_확장중 AND
    현재_포지션_없음 AND
    자금_충분함):

    → 매수 실행!
```

### 실전 예시 (삼성전자 2024-03-20)

**1단계: 스퀴즈 감지**
```
3월 10일: 대역폭 15% (정상)
3월 15일: 대역폭 8%  (46% 감소)
→ 스퀴즈 감지! ⚡
```

**2단계: 대기**
```
3월 15일~19일: 가격 횡보
→ 돌파 대기 중... ⏳
```

**3단계: 돌파 + 매수**
```
3월 20일:
  상단 밴드: ₩73,014
  현재가:    ₩74,373  ✅ 돌파!
  대역폭:    5.8% → 6.4% (확장 중)

→ 매수 실행! 🔴
  수량: 40주
  가격: ₩74,373
  금액: ₩2,974,918
```

**시각적 흐름:**
```
가격
  │
  │                     ╔═══돌파═══╗
  │                    /            \
  │  ═══스퀴즈═══     /              \
  │ /            \   /
  │/              \ /
  ├──────────────●─────★──────────────> 시간
  │            스퀴즈  매수
  │            감지   (3/20)
```

## 🔵 매도 타이밍 (청산 신호)

포지션을 보유 중일 때, 다음 3가지 조건 중 **하나라도** 충족되면 매도합니다.

### 청산 조건 1: 손절매 (Stop Loss)

**조건:**
```
현재가 < 매수가 × (1 - 손절매%)
```

**기본값:**
```
손절매 = 5%
손절가 = 매수가 × 0.95
```

**예시:**
```
매수가: ₩74,373
손절가: ₩74,373 × 0.95 = ₩70,654
현재가: ₩70,000  ✅ 손절매 발동!
```

**의미:**
- 🛡️ **손실 제한**: 최대 손실을 5%로 제한
- ⚡ **빠른 손절**: 추가 손실 방지
- 🔄 **자본 보존**: 다음 기회를 위한 자금 확보

---

### 청산 조건 2: 중간선 하향 돌파 (Middle Band Cross)

**조건:**
```
현재가 < 중간선 (20일 이동평균)
```

**예시 (삼성전자 2024-04-16):**
```
매수가:   ₩74,373
중간선:   ₩78,963
현재가:   ₩77,723  ✅ 중간선 아래로!

→ 매도 실행! 🔵
  수량: 40주
  매도가: ₩77,723
  손익: +₩133,990 (수익률 +4.50%)
```

**의미:**
- 📊 **추세 전환**: 상승 추세 → 하락 추세
- 💰 **익절**: 수익 실현
- 🎯 **타이밍**: 고점 근처에서 청산

**시각적 흐름:**
```
가격
  │         ★ 고점
  │        / \
  │   매수/   \    ● 매도
  │   /       \  /   (중간선 돌파)
  │  /         \/
  │ /   ───────●──────────  ← 중간선
  │/
  ├───────────────────────────> 시간
```

---

### 청산 조건 3: 상단 밴드 도달 (Band Upper Exit)

**조건:**
```
현재가 >= 상단 밴드
```

**예시:**
```
상단 밴드: ₩85,000
현재가:    ₩85,200  ✅ 상단 밴드 도달!

→ 매도 실행! 🔵
  이유: 목표가 도달 (익절)
```

**의미:**
- 🎯 **목표가 달성**: 상단 밴드가 목표
- 📈 **과매수 구간**: 더 오를 가능성 낮음
- 💵 **수익 확정**: 안전하게 이익 실현

---

### 청산 우선순위

```python
# 매 거래일마다 순서대로 확인

1. 손절매 확인
   if 현재가 < 매수가 × 0.95:
       → 즉시 매도 (손실 제한)

2. 중간선 돌파 확인
   elif 현재가 < 중간선:
       → 매도 (익절 또는 소폭 손절)

3. 상단 밴드 도달 확인
   elif 현재가 >= 상단_밴드:
       → 매도 (목표가 달성)
```

## 📐 파라미터 영향

### 1. 볼린저 기간 (Bollinger Period)

**기본값: 20일**

```python
bollinger_period = 20  # 조정 가능: 10~50
```

**효과:**
- **짧게 (10~15일)**: 단기 추세, 신호 빠름, 잦은 거래
- **길게 (30~50일)**: 장기 추세, 신호 느림, 적은 거래

**예시:**
```
10일: 빠른 반응, 변동성 큼 → 단타
20일: 균형 잡힌 신호 → 기본 (권장)
30일: 느린 반응, 안정적 → 장기
```

---

### 2. 스퀴즈 임계값 (Squeeze Threshold)

**기본값: 30%**

```python
squeeze_threshold_percent = 30  # 조정 가능: 20~40
```

**효과:**
- **낮게 (20~25%)**: 스퀴즈 자주 감지, 거래 증가
- **높게 (35~40%)**: 스퀴즈 드물게 감지, 거래 감소

**예시:**
```
20%: 대역폭 20% 감소만 해도 스퀴즈 → 거래 많음
30%: 대역폭 30% 감소 필요 → 적당 (권장)
40%: 대역폭 40% 감소 필요 → 거래 적음, 확실한 신호
```

---

### 3. 손절매 비율 (Stop Loss)

**기본값: 5%**

```python
stop_loss_percent = 5.0  # 조정 가능: 3~10
```

**효과:**
- **낮게 (3%)**: 손실 최소화, 자주 손절
- **높게 (7~10%)**: 변동성 수용, 드물게 손절

**예시:**
```
3%: 매수가의 3% 하락 시 손절 → 보수적
5%: 매수가의 5% 하락 시 손절 → 균형 (권장)
7%: 매수가의 7% 하락 시 손절 → 공격적
```

---

### 4. 표준편차 배수 (Std Dev Multiplier)

**기본값: 2.0**

```python
bollinger_std_dev = 2.0  # 조정 가능: 1.5~3.0
```

**효과:**
- **낮게 (1.5)**: 밴드 폭 좁음, 돌파 쉬움, 거짓 신호 많음
- **높게 (2.5~3.0)**: 밴드 폭 넓음, 돌파 어려움, 신호 확실

**예시:**
```
1.5 배: 좁은 밴드 → 자주 돌파 → 거래 많음
2.0 배: 표준 밴드 → 적당한 돌파 → 권장
3.0 배: 넓은 밴드 → 드문 돌파 → 거래 적음
```

## 🎓 전략 요약

### 핵심 흐름

```
1. 📉 스퀴즈 감지
   (대역폭 30% 감소)
   ↓
2. ⏸️ 대기
   (돌파 신호 기다림)
   ↓
3. ⚡ 상단 밴드 돌파
   (가격 > 상단 밴드)
   ↓
4. 🔴 매수 실행
   (포지션 진입)
   ↓
5. 📊 보유
   (추세 유지)
   ↓
6. 🔵 매도 실행
   (손절/중간선/목표가)
   ↓
7. 💰 손익 확정
   (다음 기회 대기)
```

### 지표 체크리스트

**매수 전 확인:**
- [ ] 스퀴즈 감지됨 (대역폭 30% 감소)
- [ ] 현재가 > 상단 밴드
- [ ] 대역폭 확장 중 (10% 이상 증가)
- [ ] 포지션 없음
- [ ] 자금 충분 (포트폴리오의 30% 이내)

**매도 전 확인:**
- [ ] 손절매 도달? (현재가 < 매수가 × 0.95)
- [ ] 중간선 하향 돌파? (현재가 < 중간선)
- [ ] 상단 밴드 도달? (현재가 >= 상단 밴드)
