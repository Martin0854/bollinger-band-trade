## 💡 개선 제안

### 1. 파라미터 최적화

**현재 최적 설정** (phase1_volume_rsi_relaxed.yaml 기반):
```yaml
squeeze_threshold_percent: 25.0
volume_filter:
  multiplier: 1.2
rsi:
  overbought: 75
  oversold: 25
confidence:
  threshold: 50
```

**추가 테스트 권장**:
1. **중간 설정** (원래 + 완화 평균):
   - squeeze: 27.5%
   - volume: 1.35x
   - RSI 과매수: 72.5
   - 신뢰도: 55점

2. **더 긴 기간** (2022-2024 2년):
   - 더 많은 거래 샘플 확보
   - 다양한 시장 환경 테스트

3. **더 많은 종목** (KOSPI 10종목):
   - 포트폴리오 분산 효과
   - 월 거래 빈도 증가

### 2. 승률 개선 방안

**목표**: 50% → 55-60%

**전략**:
1. **진입 필터 강화**:
   - RSI 과매수를 70으로 낮춤 (더 보수적)
   - Volume 배수를 1.5x로 높임
   - 신뢰도 임계값을 60점으로 높임

2. **청산 로직 개선**:
   - RSI 과매수(>75) 도달시 즉시 청산
   - 이동 평균선 이탈시 청산
   - 트레일링 스톱 도입

3. **MACD 필터 추가 (Phase 2)**:
   - 추세 확인으로 승률 개선
   - 예상 승률: 70-75%

### 3. 거래 빈도 증가 방안

**목표**: 월 0.83회 → 2-3회

**전략**:
1. **종목 수 확대**:
   - 2종목 → 10종목
   - KOSPI 대형주 포트폴리오

2. **Squeeze 임계값 조정**:
   - 25% → 22-23%
   - 더 빈번한 진입 기회

3. **다중 시간프레임**:
   - 주간 + 일간 신호 조합
   - 더 다양한 진입 기회
