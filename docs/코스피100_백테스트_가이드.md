## 🚀 빠른 시작

### 1단계: 종목 리스트 준비
```bash
poetry run python fetch_kospi_top100.py
```

**결과:**
- `kospi_top100.txt` 파일 생성 (100개 종목 코드)

### 2단계: 백테스트 실행 (테스트)
```bash
poetry run python run_multi_backtest.py
```

**기본 설정:**
- 처음 10개 종목만 테스트 (빠른 확인용)
- 2024년 1년 데이터
- 초기 자본 1000만원

### 3단계: 전체 100종목 실행

`run_multi_backtest.py` 파일에서 다음 줄 수정:
```python
# 이 줄 삭제 또는 주석 처리
max_stocks=10,  # ← 이 줄 삭제
```

다시 실행:
```bash
poetry run python run_multi_backtest.py
```

⏱️ **예상 소요 시간:** 10-20분 (네트워크 속도에 따라)

### 2️⃣ 다중 백테스트 실행

**`run_multi_backtest.py` 주요 기능:**

1. **데이터 다운로드**
   - 각 종목의 2024년 주가 데이터 다운로드
   - 실패한 종목은 자동 스킵
   - API 제한 방지 (10개마다 1초 대기)

2. **백테스트 실행**
   - 각 종목별로 독립적으로 백테스트
   - 같은 전략 파라미터 적용
   - 에러 발생 시 해당 종목만 스킵

3. **결과 집계**
   - 수익률, 승률, MDD, 샤프 비율 등
   - 상위/하위 10개 종목 표시
   - 엑셀 파일로 저장

### 3️⃣ 결과 파일 구조

**엑셀 파일 컬럼:**

|------|------|

| num_losing | 손실 거래 수 |

| avg_loss | 평균 손실 (원) |

**정렬:** 수익률 높은 순

## 📊 결과 분석

### 엑셀에서 분석

**1. 필터링:**
```excel
# 수익률 10% 이상만
=FILTER(total_return_pct >= 10)

# 승률 70% 이상만
=FILTER(win_rate_pct >= 70)

# 거래 5회 이상 + 수익
=FILTER(num_trades >= 5 AND total_return_pct > 0)
```

**2. 피벗 테이블:**
- 수익률 구간별 종목 수
- 승률 구간별 평균 수익률
- 거래 횟수별 분포

**3. 차트:**
- 수익률 분포 (히스토그램)
- 수익률 vs 승률 (산점도)
- 수익률 vs 거래횟수 (산점도)

### Python으로 추가 분석

```python
import pandas as pd

# 결과 로드
df = pd.read_excel("backtest_results_92stocks_2024-01-01_2024-12-31.xlsx")

# 1. 최고 성과 종목 찾기
top_performers = df.nlargest(20, 'total_return_pct')
print(top_performers[['stock_code', 'total_return_pct', 'win_rate_pct']])

# 2. 안정적인 종목 (높은 승률 + 낮은 MDD)
stable = df[(df['win_rate_pct'] > 70) & (df['max_drawdown_pct'] > -5)]
print(f"안정적인 종목: {len(stable)}개")

# 3. 거래 활발한 종목
active = df[df['num_trades'] >= 10]
print(f"활발한 종목: {len(active)}개, 평균 수익률: {active['total_return_pct'].mean():.2f}%")

# 4. 샤프 비율 높은 종목
high_sharpe = df[df['sharpe_ratio'] > 1.0]
print(f"고샤프 종목: {len(high_sharpe)}개")
```

## ⚙️ 파라미터 조정

### 전략 파라미터 변경

`run_multi_backtest.py` 마지막 부분 수정:

```python
results = run_multi_backtest(
    stock_codes=stocks,
    start_date="2024-01-01",
    end_date="2024-12-31",
    seed_money=10_000_000,

    # 여기서 파라미터 조정 👇
    bollinger_period=20,              # 볼린저 기간 (10~30)
    squeeze_threshold_percent=30,     # 스퀴즈 임계값 (20~40)
    stop_loss_percent=5.0,            # 손절매 (3~10)
    max_position_percent=30.0         # 최대 비중 (20~50)
)
```

### 파라미터별 효과

| 파라미터 | 값 낮추면 | 값 높이면 |
|---------|----------|----------|
| squeeze_threshold | 거래 증가, 신호 민감 | 거래 감소, 신호 보수적 |
| stop_loss | 손실 제한 강화 | 변동성 수용 |
| bollinger_period | 단기 추세 반영 | 장기 추세 반영 |
| max_position | 분산 투자 | 집중 투자 |

### 파라미터 최적화 예시

**공격적 전략:**
```python
squeeze_threshold_percent=25,  # 더 자주 진입
stop_loss_percent=7.0,         # 손실 허용 범위 증가
max_position_percent=40.0      # 집중 투자
```

**보수적 전략:**
```python
squeeze_threshold_percent=35,  # 확실한 신호만
stop_loss_percent=3.0,         # 빠른 손절
max_position_percent=20.0      # 분산 투자
```

## 🔧 문제 해결

### 문제 1: 데이터 다운로드 실패

**증상:**
```
[  5/100] 373220 ... ❌ 실패
```

**원인:**
- 종목 코드 오류
- 네트워크 문제
- API 제한

**해결:**
1. 인터넷 연결 확인
2. 종목 코드 검증:
   ```bash
   poetry run python fetch_kospi_top100.py
   ```
3. 실패한 종목은 자동으로 스킵됨 (정상)

### 문제 2: 백테스트 시간이 너무 오래 걸림

**예상 시간:**
- 10종목: ~2분
- 50종목: ~8분
- 100종목: ~15분

**개선 방법:**
1. 먼저 샘플로 테스트:
   ```python
   max_stocks=10  # 빠른 테스트
   ```

2. 기간 줄이기:
   ```python
   start_date="2024-06-01"  # 6개월만
   ```

3. 병렬 처리 (고급):
   - 향후 버전에서 지원 예정

### 문제 3: 메모리 부족

**증상:**
```
MemoryError: Unable to allocate...
```

**해결:**
1. 종목 수 줄이기:
   ```python
   max_stocks=50
   ```

2. 배치 실행:
   ```python
   # 1-50 종목
   stocks_batch1 = stocks[:50]
   run_multi_backtest(stocks_batch1, ...)

   # 51-100 종목
   stocks_batch2 = stocks[50:100]
   run_multi_backtest(stocks_batch2, ...)
   ```

### 문제 4: 거래가 전혀 없음

**증상:**
```
평균 거래 횟수: 0.0회
```

**원인:**
- `squeeze_threshold_percent` 너무 높음
- 백테스트 기간 너무 짧음

**해결:**
```python
squeeze_threshold_percent=25,  # 30 → 25로 낮춤
start_date="2023-01-01"        # 기간 연장
```
