## 1. yfinance 사용 (추천) ⭐

### 설치
```bash
poetry add yfinance
```

### 기본 사용법

**단일 종목:**
```python
import yfinance as yf
import pandas as pd

# 삼성전자 데이터 가져오기
ticker = "005930.KS"  # .KS = KOSPI, .KQ = KOSDAQ
data = yf.download(ticker, start="2024-01-01", end="2024-12-31")

# 필요한 컬럼만 추출
price_data = pd.DataFrame({
    'Open': data['Open'],
    'High': data['High'],
    'Low': data['Low'],
    'Close': data['Close'],
    'Volume': data['Volume']
})
```

## 3. 데이터 형식 요구사항

### 필수 형식

백테스트 엔진이 요구하는 형식:

```python
import pandas as pd
from datetime import datetime

# DataFrame 형식
price_data = pd.DataFrame({
    'Open': [60000, 61000, 62000, ...],      # 시가
    'High': [61000, 62000, 63000, ...],      # 고가
    'Low': [59000, 60000, 61000, ...],       # 저가
    'Close': [60500, 61500, 62500, ...],     # 종가 (필수!)
    'Volume': [1000000, 1500000, ...]        # 거래량
}, index=pd.DatetimeIndex([...]))            # 날짜 인덱스 (필수!)
```

### 검증 함수

```python
def validate_price_data(df):
    """가격 데이터가 올바른 형식인지 확인"""

    # 1. 필수 컬럼 확인
    required_columns = ['Open', 'High', 'Low', 'Close', 'Volume']
    for col in required_columns:
        if col not in df.columns:
            raise ValueError(f"필수 컬럼 누락: {col}")

    # 2. 인덱스가 DatetimeIndex인지 확인
    if not isinstance(df.index, pd.DatetimeIndex):
        raise ValueError("인덱스가 DatetimeIndex가 아닙니다")

    # 3. 결측치 확인
    if df.isnull().any().any():
        print(f"⚠️  결측치 발견: {df.isnull().sum()}")
        print("   결측치를 제거합니다...")
        df = df.dropna()

    # 4. 가격 범위 확인
    if (df['Close'] <= 0).any():
        raise ValueError("종가에 0 이하 값이 있습니다")

    if (df['High'] < df['Low']).any():
        raise ValueError("고가가 저가보다 낮은 데이터가 있습니다")

    # 5. 데이터 개수 확인
    if len(df) < 50:
        print(f"⚠️  데이터가 {len(df)}일로 부족합니다 (최소 50일 권장)")

    print(f"✅ 데이터 검증 완료: {len(df)}일")
    return df


# 사용 예시
price_data = validate_price_data(price_data)
```

### 데이터 정제

```python
def clean_price_data(df):
    """가격 데이터 정제"""

    # 1. 결측치 제거
    df = df.dropna()

    # 2. 중복 날짜 제거
    df = df[~df.index.duplicated(keep='first')]

    # 3. 날짜순 정렬
    df = df.sort_index()

    # 4. 이상치 제거 (전일 대비 ±50% 이상 변동)
    pct_change = df['Close'].pct_change()
    outliers = (pct_change.abs() > 0.5)
    if outliers.any():
        print(f"⚠️  이상치 {outliers.sum()}개 발견")
        df = df[~outliers]

    return df
```

## 4. 문제 해결

### 문제 1: 데이터를 다운로드할 수 없음

**증상:**
```
ValueError: 데이터를 찾을 수 없습니다
```

**해결책:**
1. **종목 코드 확인**: 6자리가 맞는지 (예: "005930")
2. **시장 접미사 확인**:
   - KOSPI: `.KS`
   - KOSDAQ: `.KQ`
3. **날짜 범위 확인**: 미래 날짜는 불가능
4. **인터넷 연결 확인**

**예시:**
```python
# ❌ 잘못된 코드
data = yf.download("5930", ...)      # 6자리 아님
data = yf.download("005930", ...)    # 접미사 누락

# ✅ 올바른 코드
data = yf.download("005930.KS", ...)
```

### 문제 2: 컬럼명이 다름

**증상:**
```
KeyError: 'Close'
```

**해결책:**
```python
# 한글 컬럼명을 영어로 변경
df = df.rename(columns={
    '시가': 'Open',
    '고가': 'High',
    '저가': 'Low',
    '종가': 'Close',
    '거래량': 'Volume'
})
```

### 문제 3: 인덱스가 날짜가 아님

**증상:**
```
ValueError: 인덱스가 DatetimeIndex가 아닙니다
```

**해결책:**
```python
# 날짜 컬럼을 인덱스로 변경
df['Date'] = pd.to_datetime(df['Date'])
df = df.set_index('Date')

# 또는 인덱스를 DatetimeIndex로 변환
df.index = pd.to_datetime(df.index)
```

### 문제 4: 데이터 개수가 부족

**증상:**
```
볼린저 밴드가 계산되지 않음
```

**최소 요구사항:**
- 볼린저 밴드: 20일 (기본값)
- 스퀴즈 감지: 추가 10일
- **권장: 최소 50일 이상**

**해결책:**
```python
# 더 긴 기간으로 데이터 가져오기
data = yf.download("005930.KS", start="2023-01-01", end="2024-12-31")
```

### 문제 5: 특정 날짜의 데이터만 필요

```python
# 특정 기간만 필터링
df = df.loc['2024-06-01':'2024-12-31']

# 특정 요일만 (예: 거래일만)
df = df[df.index.dayofweek < 5]  # 월~금

# 특정 달만
df = df[df.index.month == 6]  # 6월만
```
