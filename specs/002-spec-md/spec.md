## User Scenarios & Testing *(mandatory)*

### User Story 1 - 거래량 확인으로 거짓 신호 필터링 (Priority: P1)

트레이더가 볼린저 밴드 스퀴즈 돌파 시점에 거래량 증가를 확인하여 진짜 돌파와 거짓 돌파를 구분할 수 있다. 거래량이 평균 대비 1.5배 이상 증가한 경우만 진입하여 거짓 신호로 인한 손실을 줄인다.

**Why this priority**: 가장 구현이 쉽고 즉각적인 효과를 볼 수 있는 개선 사항. 기존 전략의 핵심 문제인 거짓 돌파 신호를 40~50% 감소시킬 수 있으며, 추가 계산 부담이 최소화됨.

**Independent Test**: 백테스트를 통해 거래량 필터 적용 전후의 승률과 거래 횟수를 비교 측정할 수 있으며, 거짓 신호 감소율을 정량적으로 확인 가능.

**Acceptance Scenarios**:

1. **Given** 스퀴즈가 감지되고 가격이 상단 밴드를 돌파했을 때, **When** 현재 거래량이 20일 평균 거래량의 1.5배 이상이면, **Then** 매수 신호가 생성된다
2. **Given** 스퀴즈가 감지되고 가격이 상단 밴드를 돌파했을 때, **When** 현재 거래량이 20일 평균 거래량의 1.5배 미만이면, **Then** 매수 신호가 생성되지 않는다
3. **Given** 백테스트 실행 시, **When** 거래량 필터를 활성화하면, **Then** 거래 횟수가 감소하고 승률이 10~15% 향상된다

---

### User Story 2 - RSI 과매수/과매도 필터로 진입 타이밍 최적화 (Priority: P1)

트레이더가 볼린저 밴드 돌파 시점에 RSI 지표를 확인하여 과매수 구간에서의 진입을 회피할 수 있다. RSI가 70 미만일 때만 매수하고 70 이상일 때는 매도 신호로 활용하여 고점 매수 위험을 줄인다.

**Why this priority**: 볼린저 밴드만으로는 모멘텀을 측정할 수 없는 한계를 보완. RSI는 표준 지표로 계산이 간단하며, 과매수/과매도 구간 판단으로 승률을 15~20% 향상시킬 수 있음.

**Independent Test**: RSI 필터 적용 전후의 평균 진입 가격, 평균 수익률, 손실 거래 비율을 비교하여 개선 효과를 정량화할 수 있음.

**Acceptance Scenarios**:

1. **Given** 볼린저 밴드 돌파 신호와 거래량 증가가 확인되었을 때, **When** RSI가 70 미만이면, **Then** 매수 신호가 생성된다
2. **Given** 볼린저 밴드 돌파 신호와 거래량 증가가 확인되었을 때, **When** RSI가 70 이상이면, **Then** 매수 신호가 필터링된다
3. **Given** 포지션 보유 중일 때, **When** RSI가 70을 초과하면, **Then** 과매수 청산 신호가 생성된다
4. **Given** 백테스트 실행 시, **When** RSI 필터를 적용하면, **Then** 손실 거래가 20~30% 감소한다

---

### User Story 3 - MACD로 추세 확인 및 고승률 달성 (Priority: P2)

트레이더가 볼린저 밴드 돌파 시점에 MACD 골든크로스를 확인하여 상승 추세를 검증한다. MACD선이 시그널선 위에 있고 히스토그램이 양수일 때만 진입하여 추세에 역행하는 거래를 방지한다.

**Why this priority**: 백테스트로 검증된 73~78% 승률 전략. 추세 확인을 통해 역추세 진입으로 인한 손실을 크게 줄일 수 있으나, 계산 복잡도가 높고 신호 빈도가 감소할 수 있음.

**Independent Test**: MACD 필터 적용 전후의 승률, 평균 보유 기간, 연간 수익률을 비교하여 78% 승률 목표 달성 여부를 검증할 수 있음.

**Acceptance Scenarios**:

1. **Given** 볼린저 밴드 돌파와 거래량/RSI 조건이 충족되었을 때, **When** MACD선이 시그널선보다 위에 있고 히스토그램이 양수이면, **Then** 고신뢰도 매수 신호가 생성된다
2. **Given** 볼린저 밴드 돌파와 거래량/RSI 조건이 충족되었을 때, **When** MACD선이 시그널선보다 아래에 있으면, **Then** 매수 신호가 필터링된다
3. **Given** 포지션 보유 중일 때, **When** MACD 데드크로스(MACD선 < 시그널선)가 발생하면, **Then** 추세 전환 청산 신호가 생성된다
4. **Given** 백테스트 실행 시, **When** MACD 필터를 적용하면, **Then** 승률이 70% 이상 달성되고 평균 수익/거래가 1.4% 이상이 된다

---

### User Story 4 - 다단계 신호 신뢰도 평가 시스템 (Priority: P2)

시스템이 각 보조 지표(거래량, RSI, MACD)의 조건 충족 여부에 따라 신호 신뢰도 점수(0~100점)를 계산한다. 60점 이상일 때만 진입하여 품질 높은 신호만 선택한다.

**Why this priority**: 유연한 전략 운영이 가능. 보수적 운영(70점 이상)과 공격적 운영(50점 이상) 간 전환이 쉬우며, 각 지표의 기여도를 정량적으로 분석 가능.

**Independent Test**: 신뢰도 임계값(50, 60, 70점)을 변경하며 백테스트하여 최적 임계값을 찾고, 거래 횟수와 승률의 상관관계를 검증할 수 있음.

**Acceptance Scenarios**:

1. **Given** 볼린저 밴드 돌파 신호가 발생했을 때, **When** 거래량(25점) + RSI(20점) + MACD(30점) 조건을 모두 충족하면, **Then** 신뢰도 100점 신호가 생성된다
2. **Given** 볼린저 밴드 돌파 신호가 발생했을 때, **When** 거래량과 RSI만 충족하면, **Then** 신뢰도 70점 신호가 생성되고 진입이 허용된다
3. **Given** 볼린저 밴드 돌파 신호가 발생했을 때, **When** 신뢰도가 60점 미만이면, **Then** 신호가 필터링되어 진입하지 않는다
4. **Given** 백테스트 결과 분석 시, **When** 거래 내역을 확인하면, **Then** 각 거래의 신뢰도 점수와 수익률의 상관관계를 시각화할 수 있다

---

### User Story 5 - ATR 기반 동적 손절매 (Priority: P3)

시스템이 시장 변동성(ATR)에 따라 손절매 폭을 동적으로 조정한다. 변동성이 높을 때는 손절 폭을 넓히고 낮을 때는 좁혀서 불필요한 손절을 방지한다.

**Why this priority**: 고정 5% 손절보다 유연하지만, 효과가 제한적이며 복잡도가 증가. 다른 개선 사항 적용 후 필요 시 추가 가능.

**Independent Test**: 고정 손절(5%)과 동적 손절(ATR*2)을 비교 백테스트하여 손절 빈도, 평균 손실 크기, 최종 수익률을 비교할 수 있음.

**Acceptance Scenarios**:

1. **Given** 포지션 진입 시, **When** 현재 ATR(14)이 계산되면, **Then** 손절가가 "진입가 - (ATR × 2)"로 설정된다
2. **Given** 변동성이 높은 종목의 경우, **When** ATR이 크면, **Then** 손절 폭이 5% 이상으로 확대되어 불필요한 손절을 방지한다
3. **Given** 변동성이 낮은 종목의 경우, **When** ATR이 작으면, **Then** 손절 폭이 5% 미만으로 축소되어 손실을 빠르게 차단한다

---

### Edge Cases

- 거래량 데이터가 없거나 0인 경우: 거래량 필터를 건너뛰고 다른 지표만으로 판단
- RSI 계산을 위한 충분한 과거 데이터(최소 14일)가 없는 경우: RSI 필터를 비활성화하고 경고 로그 기록
- MACD 계산을 위한 충분한 과거 데이터(최소 26일)가 없는 경우: MACD 필터를 비활성화하고 경고 로그 기록
- 모든 필터를 통과한 신호가 없어 장기간(1개월 이상) 거래가 없는 경우: 필터 임계값 자동 완화 제안
- 여러 종목에서 동시에 신호가 발생하여 자금이 부족한 경우: 신뢰도 점수가 높은 순서대로 우선순위 배정
- 백테스트 중 특정 기간에 모든 지표가 계산 불가능한 경우: 해당 기간을 건너뛰고 데이터 부족 경고 표시

## Requirements *(mandatory)*

### Functional Requirements

#### Phase 1: 기본 보조 지표 추가 (거래량 + RSI)

- **FR-001**: 시스템은 각 종목의 과거 20일 평균 거래량을 계산해야 한다
- **FR-002**: 시스템은 볼린저 밴드 돌파 시점의 거래량이 20일 평균 거래량의 1.5배 이상인 경우에만 진입 신호를 생성해야 한다
- **FR-003**: 시스템은 14일 기간의 RSI(Relative Strength Index)를 계산해야 한다
- **FR-004**: 시스템은 RSI가 70 미만일 때만 매수 신호를 생성해야 한다
- **FR-005**: 시스템은 포지션 보유 중 RSI가 70을 초과하면 과매수 청산 신호를 생성해야 한다
- **FR-006**: 시스템은 거래량 데이터가 없는 경우 거래량 필터를 건너뛰고 로그를 기록해야 한다
- **FR-007**: 시스템은 RSI 계산을 위한 충분한 과거 데이터(최소 14일)가 없는 경우 RSI 필터를 비활성화해야 한다

#### Phase 2: MACD 추세 확인 추가

- **FR-008**: 시스템은 MACD(12, 26, 9) 지표를 계산해야 한다 (MACD선, 시그널선, 히스토그램)
- **FR-009**: 시스템은 MACD선이 시그널선보다 위에 있고 히스토그램이 양수일 때만 매수 신호를 생성해야 한다
- **FR-010**: 시스템은 포지션 보유 중 MACD 데드크로스(MACD선 < 시그널선)가 발생하면 추세 전환 청산 신호를 생성해야 한다
- **FR-011**: 시스템은 MACD 계산을 위한 충분한 과거 데이터(최소 26일)가 없는 경우 MACD 필터를 비활성화해야 한다

#### Phase 3: 신호 신뢰도 평가 시스템

- **FR-012**: 시스템은 각 진입 신호에 대해 다음 기준으로 신뢰도 점수를 계산해야 한다:
  - 볼린저 밴드 돌파: 25점 (기본)
  - 거래량 조건 충족: +25점
  - RSI 조건 충족: +20점
  - MACD 조건 충족: +30점
- **FR-013**: 시스템은 신뢰도 점수가 설정된 임계값(기본 60점) 이상일 때만 진입을 허용해야 한다
- **FR-014**: 시스템은 각 거래 내역에 신호 신뢰도 점수를 기록해야 한다
- **FR-015**: 사용자는 신뢰도 임계값을 설정 파일에서 조정할 수 있어야 한다 (예: 50, 60, 70점)

#### Phase 4: ATR 기반 동적 손절매

- **FR-016**: 시스템은 14일 기간의 ATR(Average True Range)을 계산해야 한다
- **FR-017**: 시스템은 포지션 진입 시 손절가를 "진입가 - (ATR × 2)"로 설정해야 한다
- **FR-018**: 시스템은 동적 손절매 사용 여부를 설정 파일에서 활성화/비활성화할 수 있어야 한다
- **FR-019**: 시스템은 동적 손절매가 비활성화된 경우 기존 고정 5% 손절매를 사용해야 한다

#### 설정 및 백테스트

- **FR-020**: 사용자는 각 필터(거래량, RSI, MACD)를 개별적으로 활성화/비활성화할 수 있어야 한다
- **FR-021**: 사용자는 거래량 배수 임계값(기본 1.5)을 설정 파일에서 조정할 수 있어야 한다
- **FR-022**: 사용자는 RSI 임계값(기본 70)을 설정 파일에서 조정할 수 있어야 한다
- **FR-023**: 백테스트 결과는 각 필터의 적용 여부와 신뢰도 점수를 포함해야 한다
- **FR-024**: 백테스트 보고서는 필터 적용 전후의 승률, 거래 횟수, 평균 수익률을 비교해야 한다

### Key Entities

- **VolumeFilter**: 거래량 기반 신호 필터
  - Attributes: 평균 거래량 기간(기본 20일), 거래량 배수 임계값(기본 1.5배)
  - Behavior: 현재 거래량이 임계값 이상인지 검증

- **RSI Indicator**: 상대강도지수 모멘텀 지표
  - Attributes: 계산 기간(기본 14일), 과매수 임계값(기본 70), 과매도 임계값(기본 30)
  - Behavior: RSI 값 계산, 과매수/과매도 상태 판단

- **MACD Indicator**: 이동평균 수렴확산 추세 지표
  - Attributes: 빠른 EMA 기간(기본 12), 느린 EMA 기간(기본 26), 시그널 기간(기본 9)
  - Behavior: MACD선, 시그널선, 히스토그램 계산, 골든크로스/데드크로스 감지

- **SignalConfidence**: 신호 신뢰도 평가 엔티티
  - Attributes: 각 조건별 점수(볼린저 25, 거래량 25, RSI 20, MACD 30), 총 신뢰도 점수, 임계값
  - Behavior: 조건 충족 여부 확인, 총점 계산, 진입 허용 여부 판단

- **ATR Indicator**: 평균 실제 범위 변동성 지표
  - Attributes: 계산 기간(기본 14일), 손절 배수(기본 2배)
  - Behavior: ATR 값 계산, 동적 손절가 산출

- **EnhancedSignal**: 개선된 진입/청산 신호
  - Attributes: 기존 Signal 속성 + 신뢰도 점수, 각 필터 통과 여부(거래량, RSI, MACD), 동적 손절가
  - Relationships: VolumeFilter, RSI, MACD, SignalConfidence와 연결

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Phase 1(거래량 + RSI) 적용 후 백테스트 승률이 55~60%에 도달하고 연간 수익률이 +5~8%를 달성한다
- **SC-002**: Phase 1 적용 후 거짓 신호로 인한 손실 거래가 기존 대비 30% 이상 감소한다
- **SC-003**: Phase 2(MACD 추가) 적용 후 백테스트 승률이 70~75%에 도달하고 거래당 평균 수익이 1.4% 이상을 달성한다
- **SC-004**: Phase 2 적용 후 최대 낙폭(MDD)이 15% 이하로 유지된다

### Assumptions

- 거래량 데이터는 신뢰할 수 있는 출처(Yahoo Finance, KRX)에서 제공되며 정확하다고 가정
- RSI 70을 과매수 기준으로 사용하며, 이는 대부분의 한국 주식에 적용 가능한 표준 임계값으로 가정
- MACD (12, 26, 9) 파라미터는 주식 시장에서 널리 사용되는 표준 설정으로 가정
- 거래량 필터의 1.5배 임계값은 백테스트를 통해 최적화 가능하지만, 초기값으로 합리적이라고 가정
- 신뢰도 점수 배분(볼린저 25, 거래량 25, RSI 20, MACD 30)은 각 지표의 상대적 중요도를 반영하며, 추후 조정 가능

- 백테스트 성능 수치(승률 78%, 수익률 +15~20%)는 해외 연구 결과를 기반으로 하며, 한국 시장에서는 차이가 있을 수 있음
- 사용자는 기본적인 기술적 분석 지표(RSI, MACD, ATR)에 대한 이해가 있다고 가정
