## Key Technical Decisions

1. **RSI Algorithm**: Wilder's smoothing (EMA-based) with 14-day period
2. **MACD Parameters**: Standard 12/26/9 EMA configuration
3. **ATR Stop-Loss**: Wilder's ATR with 2.0x multiplier
4. **Volume Filter**: 20-day rolling mean with 1.5x threshold
5. **Confidence Scoring**: Weighted 0-100 point system (Base:25, Volume:25, RSI:20, MACD:30)
6. **Integration Pattern**: Gradual extension with Optional parameters (backward compatible)
7. **Performance**: Vectorized pandas operations with caching
8. **Testing**: 3-layer (unit/integration/contract) + hypothesis property tests
9. **Configuration**: Pydantic models + YAML files
10. **Output Format**: Enhanced Excel with confidence scores and filter results
