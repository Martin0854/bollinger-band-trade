## 1. 사전 요구사항

- **운영체제**: Windows 10/11, macOS, Linux
- **인터넷 연결**: 주가 데이터 조회를 위해 필요
- **저장 공간**: 최소 500MB

## 2. Python 설치

### Windows 사용자

1. **Python 다운로드**
   - 웹 브라우저에서 https://www.python.org/downloads/ 접속
   - "Download Python 3.x.x" 버튼 클릭 (3.9 이상 권장)

2. **설치 실행**
   - 다운로드한 파일 더블클릭
   - ⚠️ **중요**: 첫 화면에서 "Add Python to PATH" 체크박스 반드시 선택
   - "Install Now" 클릭

3. **설치 확인**
   - 시작 메뉴에서 "cmd" 검색 → "명령 프롬프트" 실행
   - 다음 명령어 입력:
   ```
   python --version
   ```
   - "Python 3.x.x" 출력되면 성공

### macOS 사용자

1. **Homebrew 설치** (이미 설치되어 있다면 건너뛰기)
   - 터미널 앱 실행 (Spotlight에서 "터미널" 검색)
   - 다음 명령어 복사 후 붙여넣기:
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. **Python 설치**
   ```bash
   brew install python
   ```

3. **설치 확인**
   ```bash
   python3 --version
   ```

## 3. 필수 패키지 설치

Python 설치 후, 트레이딩 위자드에 필요한 패키지를 설치합니다.

### Windows

1. 명령 프롬프트 실행 (시작 메뉴 → "cmd" 검색)
2. 다음 명령어 입력:
```
pip install yfinance pandas numpy
```

### macOS / Linux

1. 터미널 실행
2. 다음 명령어 입력:
```bash
pip3 install yfinance pandas numpy
```

### 설치 진행 화면 예시

```
Collecting yfinance
  Downloading yfinance-0.2.x-py3-none-any.whl (xx kB)
Collecting pandas
  Downloading pandas-2.x.x-py3-none-any.whl (xx MB)
...
Successfully installed yfinance-0.2.x pandas-2.x.x numpy-1.x.x
```

"Successfully installed"가 나오면 설치 완료입니다.

## 4. 설치 확인

모든 설치가 완료되었는지 확인합니다.

### Windows

1. 명령 프롬프트에서 trading_wizard_bundle 폴더로 이동:
```
cd C:\Users\사용자이름\Downloads\trading_wizard_bundle
```
(실제 경로에 맞게 수정)

2. 테스트 실행:
```
python daily_wizard.py --help
```

### macOS / Linux

1. 터미널에서 trading_wizard_bundle 폴더로 이동:
```bash
cd ~/Downloads/trading_wizard_bundle
```
(실제 경로에 맞게 수정)

2. 테스트 실행:
```bash
python3 daily_wizard.py --help
```

### 정상 출력 예시

```
usage: daily_wizard.py [-h] [--init] [--status] [--stocks STOCKS]
                       [--json JSON]

Daily Trading Wizard - 볼린저 밴드 스퀴즈 전략 기반 매매 추천 시스템
...
```

위와 같이 도움말이 출력되면 설치가 완료된 것입니다.

## 5. 문제 해결

### "python을 찾을 수 없습니다" 오류

**원인**: Python이 PATH에 등록되지 않음

**해결 방법 (Windows)**:
1. Python 설치 프로그램 다시 실행
2. "Modify" 선택
3. "Add Python to environment variables" 체크
4. 컴퓨터 재시작

**해결 방법 (macOS)**:
- `python` 대신 `python3` 사용

### "pip을 찾을 수 없습니다" 오류

**해결 방법 (Windows)**:
```
python -m pip install yfinance pandas numpy
```

**해결 방법 (macOS)**:
```bash
python3 -m pip install yfinance pandas numpy
```

### "Permission denied" 오류 (macOS/Linux)

```bash
pip3 install --user yfinance pandas numpy
```

### 네트워크 관련 오류

- 회사/학교 네트워크에서는 방화벽으로 인해 설치가 안 될 수 있습니다
- 개인 인터넷(집, 모바일 핫스팟)에서 시도해 보세요

### yfinance 데이터 조회 오류

yfinance는 Yahoo Finance에서 데이터를 가져옵니다. 간혹 서버 문제로 오류가 발생할 수 있습니다.

**해결 방법**:
- 잠시 후 다시 시도
- 인터넷 연결 확인
- 장 마감 후(오후 4시 이후) 실행 권장
