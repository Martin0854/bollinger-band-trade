## 1. 시작하기 전에

### 폴더 위치 확인

모든 명령어는 `trading_wizard_bundle` 폴더 안에서 실행해야 합니다.

**Windows**:
```
cd C:\Users\사용자이름\Downloads\trading_wizard_bundle
```

**macOS**:
```bash
cd ~/Downloads/trading_wizard_bundle
```

### 실행 시간

- **장 마감 후 오후 4시 이후** 실행을 권장합니다
- 장중에 실행하면 실시간 가격이 아닌 전일 종가 기준으로 분석됩니다

## 2. 일일 위자드 사용법

### 2.1 포트폴리오 초기화 (최초 1회)

처음 시작할 때 초기 자본금 100만원으로 포트폴리오를 생성합니다.

**Windows**:
```
python daily_wizard.py --init
```

**macOS**:
```bash
python3 daily_wizard.py --init
```

**출력 예시**:
```
========================================
  Daily Trading Wizard 초기화
========================================

초기 자본: 1,000,000 KRW
시작일: 2026-01-05
저장 파일: portfolio_state.json

포트폴리오가 초기화되었습니다.
```

### 2.2 일일 추천 생성

매일 장 마감 후 실행하여 다음날 매수/매도 추천을 받습니다.

**Windows**:
```
python daily_wizard.py
```

**macOS**:
```bash
python3 daily_wizard.py
```

**출력 예시**:
```
========================================
  Daily Trading Wizard - 2026-01-06
========================================

[매도 추천] ────────────────────────────
  없음

[매수 추천] ────────────────────────────

  1. 삼성전자 (005930)
     추천가: 75,000 KRW
     수량: 1주
     신뢰도: 75점

     ─── 판단 근거 ───
     - 볼린저 밴드 상단 돌파
     - 거래량 1.8배 증가
     - RSI 55 (중립)
     - MACD 상승 추세

  2. SK하이닉스 (000660)
     ...

========================================
  portfolio_state.json 저장 완료
========================================
```

### 2.3 현재 상태만 확인

추천을 생성하지 않고 현재 포트폴리오 상태만 확인합니다.

**Windows**:
```
python daily_wizard.py --status
```

**macOS**:
```bash
python3 daily_wizard.py --status
```

## 5. 매매 워크플로우

실제 매매 시 따라야 할 일일 루틴입니다.

### 5.1 전체 흐름

```
┌─────────────────────────────────────────────────────────┐
│  [1단계] 장 마감 후 오후 4시                             │
│                                                         │
│  python daily_wizard.py 실행                            │
│  → 매수/매도 추천 확인                                   │
│  → portfolio_state.json 자동 저장                       │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│  [2단계] 다음날 장 시작 (오전 9시)                       │
│                                                         │
│  추천 종목 주문 실행:                                    │
│  - 매수: 시장가 또는 추천가 근처 지정가                  │
│  - 매도: 시장가 또는 추천가 근처 지정가                  │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│  [3단계] 장 마감 후 (저녁)                               │
│                                                         │
│  portfolio_state.json 수정:                             │
│  - actual_price: 실제 체결가 입력                       │
│  - executed: true로 변경                                │
│                                                         │
│  (자세한 방법은 '6. JSON 파일 수정 방법' 참조)           │
└───────────────────────────┬─────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│  [4단계] 다음날 장 마감 후                               │
│                                                         │
│  python daily_wizard.py 실행 (1단계로 돌아감)            │
│  → 체결된 주문 자동 처리                                 │
│  → 새로운 추천 생성                                      │
└─────────────────────────────────────────────────────────┘
```

### 5.2 주의사항

- 장 마감 후(오후 4시 이후)에 위자드를 실행하세요
- 추천은 참고용입니다. 최종 투자 결정은 본인 판단으로 하세요
- 체결가 입력을 잊으면 다음 추천이 정확하지 않을 수 있습니다

## 6. JSON 파일 수정 방법

`portfolio_state.json` 파일을 직접 수정하여 체결 정보를 입력합니다.

### 6.1 파일 열기

**Windows**:
- 메모장으로 열기: 파일 우클릭 → 연결 프로그램 → 메모장
- 또는 Visual Studio Code 등 코드 편집기 사용 권장

**macOS**:
- 텍스트 편집기로 열기: 파일 우클릭 → 다음으로 열기 → 텍스트 편집기
- 또는 터미널에서: `open -a TextEdit portfolio_state.json`

### 6.2 체결 정보 입력

`pending_orders` 섹션에서 주문을 찾아 수정합니다.

**수정 전**:
```json
{
  "pending_orders": [
    {
      "recommendation_date": "2026-01-06",
      "stock_code": "005930",
      "stock_name": "삼성전자",
      "action": "BUY",
      "recommended_price": 75000,
      "actual_price": null,
      "quantity": 1,
      "executed": false
    }
  ]
}
```

**수정 후**:
```json
{
  "pending_orders": [
    {
      "recommendation_date": "2026-01-06",
      "stock_code": "005930",
      "stock_name": "삼성전자",
      "action": "BUY",
      "recommended_price": 75000,
      "actual_price": 74800,
      "quantity": 1,
      "executed": true
    }
  ]
}
```

### 6.3 수정 포인트

| 항목 | 수정 전 | 수정 후 | 설명 |
|------|---------|---------|------|
| actual_price | null | 74800 | 실제 체결된 가격 |
| executed | false | true | 체결 완료 표시 |

### 6.4 주의사항

- **쉼표(,)와 따옴표("")를 정확히 입력하세요**
- **null은 따옴표 없이 입력합니다** (숫자도 따옴표 없이)
- **true/false는 소문자로, 따옴표 없이 입력합니다**
- 저장 후 위자드를 다시 실행하면 자동으로 처리됩니다

### 6.5 JSON 형식 오류 확인

파일 저장 후 오류가 나면 https://jsonlint.com/ 에서 검증할 수 있습니다.

## 7. 전략 이해하기

### 7.1 볼린저 밴드 스퀴즈 전략

볼린저 밴드는 주가 변동성을 측정하는 지표입니다.

```
   상단 밴드  ─────────────────────────  (20일 이동평균 + 2×표준편차)
              \                    /
               ╲__            __╱
                  ╲__    __╱
   중심선     ─────────╲__╱───────────────  (20일 이동평균)
                  __╱╲__
               __╱      ╲__
              /            \
   하단 밴드  ─────────────────────────  (20일 이동평균 - 2×표준편차)
```

**매수 시그널**: 종가가 상단 밴드를 돌파할 때
**매도 시그널**: 종가가 하단 밴드 아래로 내려갈 때 또는 -5% 손절

### 7.2 신뢰도 점수

모든 매수 추천에는 신뢰도 점수가 있습니다 (0~100점).

| 조건 | 점수 | 설명 |
|------|------|------|
| 기본 | 25점 | 상단 밴드 돌파 시 기본 점수 |
| 거래량 | +25점 | 20일 평균 대비 1.5배 이상 |
| RSI | +20점 | 30~70 범위 (과매수/과매도 아님) |
| MACD | +30점 | 히스토그램 > 0 (상승 추세) |
| **합계** | **최대 100점** | |

**60점 이상**일 때만 매수 추천됩니다.

### 7.3 리스크 관리

| 항목 | 설정값 | 설명 |
|------|--------|------|
| 최대 포지션 | 15개 | 동시 보유 가능 종목 수 |
| 포지션 비중 | 10% | 종목당 최대 투자 비율 (약 10만원) |
| 손절선 | -5% | 손실 제한 |

## 8. 자주 묻는 질문

### Q1. "데이터를 가져올 수 없습니다" 오류가 나요

**A**: 인터넷 연결을 확인하세요. Yahoo Finance 서버 문제일 수 있으니 잠시 후 다시 시도하세요.

### Q2. 추천 종목이 하나도 없어요

**A**: 정상입니다. 시장 상황에 따라 매수 조건을 충족하는 종목이 없을 수 있습니다.

### Q3. 실제로 매매해도 되나요?

**A**: 이 시스템은 **참고용 도구**입니다.
- 과거 백테스트 결과가 미래 수익을 보장하지 않습니다
- 최종 투자 결정은 본인 책임입니다
- 소액으로 시작하여 시스템을 충분히 이해한 후 투자 규모를 조절하세요

### Q4. 포트폴리오를 초기화하고 싶어요

**A**: `portfolio_state.json` 파일을 삭제하고 `--init` 옵션으로 다시 시작하세요.

```
# Windows
del portfolio_state.json
python daily_wizard.py --init

# macOS
rm portfolio_state.json
python3 daily_wizard.py --init
```

### Q5. 다른 종목 리스트로 분석하고 싶어요

**A**: `--stocks` 옵션으로 종목 리스트 파일을 지정할 수 있습니다.

```
python daily_wizard.py --stocks my_stocks.txt
```

종목 파일 형식 (한 줄에 하나씩):
```
005930
000660
035720
...
```

### Q6. 장중에 실행하면 어떻게 되나요?

**A**: 전일 종가 기준으로 분석됩니다. 정확한 분석을 위해 장 마감 후(오후 4시 이후) 실행을 권장합니다.

### Q7. 수수료와 세금은 반영되나요?

**A**: 현재 버전에서는 반영되지 않습니다. 실제 거래 시 약 0.25% (증권사 수수료 + 세금)를 고려해야 합니다.

---

**면책 조항**: 이 소프트웨어는 교육 및 연구 목적으로 제공됩니다. 투자 결정에 따른 손실에 대해 개발자는 책임지지 않습니다. 투자는 항상 본인의 판단과 책임 하에 진행하시기 바랍니다.
